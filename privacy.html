Privacy Policy

1. Who this applies to

This policy covers a private automation tool used by one individual (the owner) to manage their own YouTube channels ("the Tool"). It is not offered to the public; no visitor can log in, submit content, or otherwise use it.

2. What data the Tool accesses

  • Upload operations for the owner's own channels (video files and their titles/descriptions) through the YouTube Data API (scopes: youtube.upload).
  • Read-only channel and video information of the owner's own channels — titles, publish dates, view counts, likes, comments, watch-time metrics, traffic sources and similar statistics — through the YouTube Data API and YouTube Analytics API (scopes: youtube.readonly, yt-analytics.readonly).

The Tool never reads, stores or processes data from any other YouTube account, viewer, or third party beyond public statistics of the owner's own videos.

3. Where data is stored

All data stays on the owner's private, self-hosted server (a single cloud instance to which only the owner has access). Data isn't sold, rented, traded or shared with anyone. Nothing is sent to advertising or analytics networks.

4. Retention

Channel and video metadata is kept indefinitely as an operational record; daily statistics snapshots used for performance review are also kept long-term. Access is restricted to the owner via an SSH tunnel; all access is logged.

5. Token security

OAuth tokens issued by Google are stored on the owner's server only, used solely by the Tool for the purposes above, and are never shared. If this policy-relevant setup changes, the token may be revoked at any time in the owner's Google Account.

6. Your rights

Because the Tool processes only the owner's own data, there is no third-party data from visitors to manage. If you believe this tool has accessed data it should not have, contact the owner using the support e-mail address listed in the Google API Services consent screen.

7. Changes

Any future functional change will be reflected here with an updated "Last updated" date. Material changes will also be reflected in the project documentation.

8. Contact

Questions about this policy or the Tool? Reach the owner via the support e-mail registered in this application's Google branding configuration.
